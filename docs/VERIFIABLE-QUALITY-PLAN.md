# 검증 가능한 번역 완료를 위한 구현 계획

## 현재 기준선과 목표

2026-10-26의 서로 다른 분야 30편 재검사 결과는 `completed` 6편, `partial` 24편, 작업 자체의 `failed` 0편이다. 24편에 `translation_failed`가 있고, `rendered_prose_missing` 4건과 `figure_legend_incomplete` 2건은 일부 문서에 겹친다. `total_untranslated_units=0`은 번역기에 들어온 문장에 대한 수치다. 원본에서 추출되지 않은 글이 없다는 증거가 아니다.

목표는 두 층으로 나눈다.

1. **프로그램이 보장할 수 있는 것:** 원문에서 읽을 수 있다고 판정한 각 영역이 번역·원문 보존·검토 필요 중 하나로 끝나고, 근거가 없는 영역이나 검사에 실패한 영역이 `completed`로 표시되지 않도록 한다. 완료 판정은 버전과 입력 해시에 묶인 검사 증거를 요구한다.
2. **의미 정확도를 확인하는 것:** 원문과 결과의 주장·조건·부정·수량·대상·관계를 대조한다. 자동 검사는 결함을 찾고 교정하지만, 임의의 새 PDF에 대해 의미 오류가 0개라고 논리적으로 증명할 수는 없다. 무오류 인증이 필요한 문서는 최종 사람 검토와 승인 기록까지 포함한다.

따라서 UI의 `완료`는 **자동 검사 완료**, `검증 완료`는 **독립 검토자 승인까지 완료**로 분리한다. `검증 완료`를 요청한 문서는 표본만 보는 것이 아니라 읽을 수 있는 모든 원문 영역과 번역 영역, 최종 PDF의 모든 쪽을 대조하고 검토자·시간·수정 이력을 남긴다. 읽을 수 없는 원문이나 해결되지 않은 충돌은 `검토 필요`로 남긴다. 오류를 지우기 위해 검사 기준을 낮추지 않는다.

## 영역별 증거 장부

각 원문 쪽의 본문, 제목, 표 셀, 캡션, 그림, 수식, 참고문헌에 안정적인 `region_id`를 부여한다. 장부에는 다음을 남긴다.

| 단계 | 필수 증거 |
| --- | --- |
| 원본 | 파일 해시, 쪽 번호, 좌표, 렌더 이미지 해시, 텍스트층·OCR 후보 |
| 해석 | 영역 유형, 열/표 읽기 순서, 사용한 추출기, 대안 후보와 선택 이유 |
| 번역 | 원문 지문, 문단/문장 ID, 보호 토큰, 번역 후보, 모델·설정·체크포인트 |
| 검사 | 누락·숫자·수식·식별자·명제 대조 결과, 검사의 버전과 반례 |
| 출력 | 한국어 PDF 좌표, 대응 원문 영역, 렌더 확인 결과, 원문 보존 사유 |

원본 영역 중 결과 연결이 없는 것이 하나라도 있으면 완료 불가다. 참고문헌·수식·그림처럼 번역하지 않기로 정한 영역도 `의도적 원문 보존`이라는 결과를 갖는다. 검사 통과 주장은 모델 응답이 아니라 장부와 최종 파일을 읽은 검사기의 결과로 저장한다.

## 구현 순서

### 1. 원문 누락 검사부터 완료 판정에 연결

- 기존 `source_coverage`의 행 대조에 원본 렌더와 독립 OCR 표본을 추가한다. 모든 쪽에서 텍스트층·좌표 대조를 하고, 스캔/추출 충돌 영역에만 OCR을 실행한다.
- 그림 내부 글, 페이지 장식, 참고문헌을 본문 누락으로 잘못 계산하지 않도록 영역 유형을 먼저 판정한다. 두 추출기가 충돌하고 해결 근거가 없으면 해당 영역을 검토 대상으로 남긴다.
- **통과 조건:** 합성 자료에 삽입한 한 줄 누락, 열 순서 바뀜, 표 셀 누락, 페이지 경계 문장 누락을 전부 탐지한다. 별도 정상 자료에서 오탐을 측정한 뒤에만 진단 검사를 완료 차단 조건으로 승격한다.

### 2. 원문 영역부터 결과 PDF까지 연결

- `region_id`를 PDF 분석, 번역 단위, 체크포인트, 조판, 최종 PDF에 유지한다. 재실행 시 원본 해시나 영역 경계가 달라지면 해당 증거만 무효화한다.
- 최종 PDF를 다시 파싱하고 렌더링해 영역별 글 누락, 겹침, 잘림, 페이지 이탈, 표/캡션 위치, 그림 범례 연결을 확인한다. 텍스트 추출만으로 판정이 어려운 곳은 해당 영역의 픽셀 비교를 사용한다.
- **통과 조건:** 모든 읽을 수 있는 원문 영역이 번역·보존·검토 대상 중 하나에 대응하고, 알려진 출력 누락/겹침/잘림을 완료로 통과시키지 않는다.

### 3. 의미를 작은 주장 단위로 대조

- 문단을 동작·대상·조건·부정·비교·수량·단위·인용으로 분해한다. 한 숫자의 출현 횟수보다 **무엇에 적용되는 숫자인지**를 먼저 대조한다. 예를 들어 `제곱근 안에 1을 더한다`와 `제곱근을 취한 뒤 1을 뺀다`는 별도 동작이다.
- 번역 모델과 검수 모델은 서로의 판정을 보지 않고 원문과 결과를 비교한다. 불일치가 있으면 각각 원문 구절과 결과 구절을 인용해야 한다. 동일 모델의 재진술만으로 충돌을 해소하지 않는다.
- 규칙 검사로 확정 가능한 숫자·식별자·자리표시자는 먼저 결정하고, 의미 대조는 위험 문단에 집중한다. 모델 간 판정 충돌은 추가 검사 또는 검토 대상으로 남긴다.
- **통과 조건:** 의도적으로 심은 부정 반전, 조건 삭제, 주체/목적어 교환, 수량의 대상 교환, 연산 순서 삭제, 표 행 오염이 모두 완료 판정에서 차단된다.

### 4. 근거가 있는 국소 복구와 중단 조건

- 오류 유형별로 재추출 → 문장 재분할 → 부분 교정 → 문단 재번역 → 대안 조판의 순서를 정한다. 매 단계는 해당 원문 영역과 검사 증거만 갱신하고 이미 통과한 영역은 재사용한다.
- 교정 후보는 이전 후보와 독립적으로 원문 보존 검사, 주장 대조, 최종 PDF 검사를 통과해야 한다. 같은 오류가 반복되거나 두 후보가 충돌하면 추가 재시도 대신 검토 대상으로 넘긴다.
- **통과 조건:** 합성 결함은 지정된 영역만 재처리하고 복구한다. 복구 실패 시에도 이전 결과와 체크포인트가 남으며, `completed`로 오인되지 않는다.

### 5. 독립 자료로 기준 고정

- 현재 30편은 개발·원인 분석 자료로 사용한다. 형식·분야·스캔 품질별 새 PDF를 별도 평가 세트로 모으고 개발 중에는 정답/판정을 숨긴다. 사용 권한이 확인된 자료만 저장하며 원문은 Git에 넣지 않는다.
- 문서별 결과뿐 아니라 **원문 영역 재현율, 실제 의미 오류, 잘못된 완료 판정, 정상 문단 오탐, 평균/상위 95% 처리 시간, 추가 모델 호출**을 기록한다. 검사 자체에 숫자/부정/누락을 주입하는 변형 시험도 수행한다.
- 첫 공개 게이트는 새 자료 **최소 100편**, 주요 PDF 유형별 표본과 합성 결함 세트에서 **치명적인 잘못된 완료 0건**, **주입한 치명 결함 탐지 100%**, 사람 검토 표본에서 발견한 결함의 원인과 재현 시험 보유다. 이는 표본에서의 결과이지 모든 미래 PDF의 무오류 증명은 아니다. 표본이 늘어날 때까지 실패율과 신뢰구간도 함께 보고한다.

## 비용과 처리 시간 원칙

텍스트층·좌표·해시 검사는 전 영역에 적용한다. 독립 OCR, 두 번째 의미 검사, 픽셀 대조, 모델 재번역은 충돌하거나 위험도가 높은 영역에서만 실행한다. 장부는 검사 결과를 원문 해시·후보 지문·검사 버전에 묶어 재사용한다. 매 변경마다 품질 향상과 함께 문서당 시간, 추가 GPU 초, 재처리 영역 비율을 비교한다. 속도가 크게 악화되는 단계는 선택 조건을 좁히고 다시 측정한다.
