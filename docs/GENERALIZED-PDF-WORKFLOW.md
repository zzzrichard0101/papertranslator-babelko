# 다양한 PDF를 위한 검증·복구 워크플로우

## 목표와 판정 원칙

원본의 모든 읽을 수 있는 영역을 추적하고, 번역과 PDF 출력까지 대응 관계를 유지한다. 새 문서에서 예상하지 못한 형태가 나와도 전체 작업을 잃지 않고 해당 영역의 다른 처리 방법을 시도한다. 증거가 부족하면 `completed`로 표시하지 않는다. 훼손되거나 읽을 수 없는 원본까지 무오류로 번역한다는 보장은 하지 않는다.

현재 `translation_tracking`은 번역기로 들어온 문장만 센다. `rendered_prose`는 그 출력의 일부가 저장된 PDF에 나타나는지 확인한다. 따라서 **원문 → 구조 분석** 단계에서 빠진 글은 별도 검사 없이는 통과할 수 있다. 30편 평가의 기준선과 각 수정 전후 결과는 로컬 `test_vault/`에만 보관한다.

## 공통 기록

각 원문 영역에 문서 해시, 원본 쪽 번호, 좌표, 원문 지문, 추출 방법, 구조 유형, 읽기 순서, 신뢰도, 처리 결과를 연결한다. 수식·그림·표·코드·참고문헌의 `원문 보존`도 의도적인 결과로 기록한다. 검사기는 모델이 작성한 성공 주장과 별도로 원본 및 최종 PDF를 읽는다. 시간과 모델 호출 횟수는 영역과 단계별로 기록한다.

## 단계와 통과 기준

| 단계 | 구현 | 다음 단계로 넘어갈 조건 |
| --- | --- | --- |
| 1. 원문 텍스트층 대조 | 원본/로컬 OCR 입력의 텍스트 행을 번역 직전 PDF 구조 문단과 대조한다. 누락 의심 행을 쪽·텍스트 지문과 함께 `source-coverage.json`에 남긴다. 첫 도입은 진단만 수행한다. | 합성 누락을 탐지하고, 정상·2칼럼·스캔 표본에서 오탐을 수집한다. 검사 실행이 번역이나 체크포인트를 바꾸지 않는다. |
| 2. 원본 픽셀 대조 | 텍스트층이 없거나 신뢰도가 낮은 영역만 독립 OCR로 확인한다. 그림 속 글과 본문을 분리하고 서로 다른 추출 결과의 차이를 기록한다. | 원문에 보이는 본문 누락을 별도로 탐지한다. OCR 오류나 그림 글을 본문 누락으로 단정하지 않는다. |
| 3. 구조 대안 선택 | 열 순서, 이어지는 문장, 표 셀, 인용·참고문헌의 해석이 불확실한 영역에만 다른 분석 방법을 적용한다. 모든 대안과 선택 근거를 보존한다. | 알려진 구조 오류를 문서명 예외 없이 복구하고, 새로운 자료의 원문 대응 관계를 유지한다. |
| 4. 번역·조판 대응 | 원문 영역 ID를 번역 단위와 최종 PDF 위치까지 전달한다. 수식·코드·식별자·참고문헌은 유형별 정책을 적용한다. | 원문 영역마다 번역 또는 의도적 원문 보존 결과가 하나 이상 존재한다. |
| 5. 독립 출력 검사·국소 복구 | 최종 PDF를 다시 읽고 렌더링해 영역별 누락, 숫자·식별자 변화, 겹침·쪽 이탈을 확인한다. 문제 영역만 제한 횟수 재처리한다. | 알려진 훼손 표본을 모두 차단하고, 정상 표본의 오탐을 독립 라벨로 측정한다. 실패를 검사를 완화하여 통과시키지 않는다. |
| 6. 다양한 자료의 회귀 평가 | 학술 분야뿐 아니라 태그 유무, 스캔 품질, 회전, 다단, 표, 수식, 참고문헌, 암호·손상 PDF를 구분해 보지 않은 자료로 검증한다. | 처리 완료율, 실제 누락률, 잘못된 통과율, 문서당 시간과 선택적 재처리 비용을 함께 공개한다. |

## 실행 규칙

- 값싼 텍스트층·좌표 검사는 전 페이지에 적용하고, OCR·두 번째 모델·재조판은 의심 영역에만 사용한다.
- 오류가 발생하면 단계, 쪽, 영역 ID, 원문/출력 지문, 재시도 횟수를 남긴다. 동일 실패가 반복되면 체크포인트를 보존하고 배치를 중지한다.
- `completed`는 자동 검사를 모두 통과했다는 뜻이며 의미 정확도의 증명은 아니다. 검사 근거가 부족하면 `partial` 또는 입력 불가 상태를 명시한다.
- 기존 공개 원문, 모델, 사용자 결과, 상위 BabelDOC/PDFMathTranslate 코드는 수정하지 않는다. 개발 코퍼스와 PDF는 무시된 `test_vault/`에 보관한다.

- [x] 원문 텍스트층·이미 실행된 보조 OCR의 행과 IL 문단에 안정적인 ID를 부여하고, 연결 상태와 같은 위치의 독립 추출 일치 여부를 `SourceEvidence.json`에 저장한다. 출력 `Quality.json`에 장부 해시를 남긴다. 여전히 진단 단계이며 픽셀 전체 누락 증명은 아니다.

- [ ] 3단계: 구조 대안 선택
- [ ] 4단계: 영역 ID의 최종 PDF 연결
- [ ] 5단계: 독립 출력 검사와 국소 복구
