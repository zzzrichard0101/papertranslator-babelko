# 문서 우주: PDF 단어의 3D 입자 지도

**문서 우주**는 선택한 PDF에서 읽힌 단어를 하나의 3D 공간에 펼칩니다. PDF 페이지 이미지나 문단 카드는 이 화면에 표시하지 않습니다. 번역 결과를 변경하지 않는 읽기 전용 탐색 화면입니다.

## 입자는 무엇을 뜻하나요?

| 표현 | 계산에 쓰는 자료 | 해석 |
| --- | --- | --- |
| 입자 하나 | 고유 단어 하나 | 대소문자를 통합한 원문 단어 |
| 입자 크기 | 단어 등장 횟수 | 자주 나온 단어가 더 큼 |
| 색과 옅은 구름 | 함께 등장한 단어들의 연결 집단 | 같은 문맥에서 자주 만난 단어들의 묶음 |
| 입자 사이 거리 | 한 텍스트 블록 안에서 가까이 나온 단어들의 연결 | 원문에서 함께 등장한 경향. **의미 유사도는 아님** |
| 깊이 | 관계 그래프의 3D 배치와 평균 등장 쪽 | 문서 흐름을 일부 반영한 탐색용 좌표 |
| 가는 선 | 강한 단어 연결 일부 | 화면 복잡도를 줄이기 위해 상위 연결만 표시 |

텍스트 추출 → 단어별 빈도와 등장 쪽 집계 → 같은 블록에서 가까이 등장한 단어 연결 → 3D 그래프 배치와 군집 계산 → Qt Quick 3D의 작은 둥근 점으로 렌더링하는 순서로 처리합니다. 분석은 별도 로컬 프로세스에서 실행해 번역 작업실 화면이 멈추지 않게 하고, 같은 PDF를 다시 열면 로컬 캐시를 사용합니다. 화면의 점은 번역 모델이 생성하지 않습니다.

드래그로 회전하고 휠로 확대할 수 있습니다. 작은 점도 누르기 쉽도록 마우스 주변의 가장 가까운 단어를 선택합니다. 입자를 클릭하거나 오른쪽에서 검색하면 등장 횟수, 등장한 쪽의 수, 같이 나온 단어가 표시됩니다. 상위 단어는 입자 옆에도 이름이 보입니다. **2D 보기**는 3D 그래픽 모듈을 사용할 수 없는 환경을 위한 같은 데이터의 평면 표현입니다.

## 범위와 한계

- 고유 단어가 많아도 가장 대표적인 480개만 입자로 표시하며, 가는 선은 최대 280개만 그립니다. 오른쪽에 전체 고유 단어 수와 표시 수가 나옵니다.
- 논문의 수식, 그림 안에 그려진 글자, 외곽선으로 변환된 글자는 일반 텍스트 추출만으로 읽히지 않습니다. 스캔본은 해당 작업에서 이미 만든 로컬 OCR 텍스트 PDF가 있으면 재사용합니다. OCR이 아직 없으면 빈 공간으로 나올 수 있습니다.
- 가까운 거리는 함께 등장한 기록과 그래프 배치의 결과입니다. 뜻이 비슷하다거나 인과관계가 있다는 증거가 아닙니다. 쪽 위치는 상세 정보에 수치로 나타납니다.
- 그래픽 효과는 번역 속도나 PDF 결과물의 품질을 바꾸지 않습니다. 점과 연결선 수를 제한했지만 오래된 그래픽 장치에서는 2D 보기가 더 원활할 수 있습니다.
- 기존 설치를 갱신할 때 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -SkipModels`를 실행하면 모델을 다시 다운로드하지 않고 필요한 3D 모듈을 설치할 수 있습니다.

## 구현과 출처

3D 카메라, 둥근 점과 클릭 판정은 [Qt Quick 3D](https://doc.qt.io/qt-6/qtquick3d-index.html)를 사용합니다. 그래프 배치와 군집 분석에는 로컬 NetworkX를 사용합니다. 원문 PDF나 단어 목록을 외부 서비스에 전송하지 않습니다. 이 화면은 시각화이며 번역 품질 검수 결과로 사용하지 않습니다.
